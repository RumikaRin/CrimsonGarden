# Antigravity Solo Workflow

When running Antigravity Solo on Antigravity IDE, follow `GEMINI.md` plus
`H5S/docs/GEMINI_SOLO_WORKFLOW.md` and `H5S/docs/MODEL_ROUTER.md`.

Default strengths:
- UI/UX Designer for visual direction, responsive states, interaction states,
  accessibility notes, and UI QA.
- Cinematic landing pages via `H5S/docs/UI_PRESETS/CINEMATIC_LANDING_BUILDER.md`
  when the task is marketing/landing, not dashboard/admin UI.
- Coder only after the UI/UX brief or implementation scope is clear.

Shared safety still applies even in solo mode:
- For longer tasks, update `H5S/progress.md` (or synchronize it from the native `task.md` of the Antigravity IDE).
- Choose model tier by task before large planning/coding/review work.
- Before editing many files, name the files and verification command.
- For Next.js work, read the relevant guide in `node_modules/next/dist/docs/`
  before writing code.
- Prioritize native IDE tools over shell commands and use the native `implementation_plan.md`, `task.md` and `walkthrough.md` files in the brain directory for interactive plan management.
